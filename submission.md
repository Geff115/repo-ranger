## 📝 Summary
RepoRanger automates GitHub issue triage, saving maintainers 15-30 minutes per issue through AI-powered classification, intelligent commenting, and strategic weekly insights.

## ⚡ Key Features
- **Real-time Issue Triage**: Instant AI classification and labeling
- **Smart Analysis**: AI-generated context with affected files
- **Weekly Intelligence**: Strategic recommendations based on issue patterns
- **Live Dashboard**: Beautiful analytics on Vercel

## 🛠️ Technologies
- **Kestra**: Workflow orchestration (2 flows, webhook + cron triggers)
- **Groq**: AI inference with Llama 3.3 70B
- **Vercel**: Production dashboard deployment
- **CodeRabbit**: Automated code reviews
- **GitHub API**: Repository integration
